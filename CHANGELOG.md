# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0]

Initial release: the icon set extracted from [KernPage](https://github.com/jmitchell238/kernpage).

- 108 icons on a 16 px grid with `currentColor` ink, plus hand-tuned `@20`, `@24` (and for some icons `@28`, `@35`, `@42`) variants.
- Core API: `names`, `svg`, `variants`, `design_size`, `render_rgba`, `Mode`, `Color`, `grey_of`.
- `egui` feature (default): `paint`, `rasterise`, `rasterise_svg`, `INK`.
- Examples: `render_svg`, `make_gallery`.
